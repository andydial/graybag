# Andy's prep pack — drafts for everything with external latency

**Everything here is a draft for you to check and submit, not a decision I have made.** The
point is that you are never staring at an empty form: the answers are pre-filled from what the
code actually does, with the source cited so you can verify rather than trust.

None of this compresses later. A store review takes the days it takes; a DLT template approval
takes the days it takes. Started today in parallel, they run underneath the build instead of
after it.

## How to use it

1. Read the draft. Where it says **[YOU DECIDE]**, that is a real gap only you can fill.
2. Correct anything wrong — the drafts are derived from the code, so if a draft is wrong it
   usually means the code is doing something we did not intend, and that is worth knowing.
3. Submit, then tell me what you submitted so the repo matches reality.
