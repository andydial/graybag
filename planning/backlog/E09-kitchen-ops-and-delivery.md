## Context

Kitchen staff today log in via "Admin Login" on the website and see all orders. Kitchens serve multiple schools. The delivery function may later be handled by a separate party, so `orders.mark_delivered` is a distinct permission from refund and financial access.

- [x] `E09-29` **An undo window on every status tap — the Gmail pattern, and it needs no server change.** Gmail's "Undo Send" does not recall a sent mail; it holds the send and cancels it. Deferring the request by ten seconds needs no migration and leaves nothing in the audit trail to explain. One pending batch at a time — a second action flushes the first — and the pending write is flushed on `visibilitychange`, `pagehide` and any reload, because a deferred write that never happens is the silent no-op this screen exists to avoid. **Layer (a) of three**; (b) and (c) are corrections after the window and genuinely need the server — `E09-24`, and `docs/kitchen-write-contract.md` §1
