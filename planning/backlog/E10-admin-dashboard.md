- [x] `E10-19` **Edit an override from `/admin/config`.** The write half of `E10-06`. Each overridable setting carries a collapsed `<details>` editor — collapsed because this screen is read far more often than written, and nine open forms would bury the question it exists to answer. **One setting per request, and only that setting's key in the body**: the endpoint treats an absent key as "leave it alone" and `null` as "clear it", so posting the whole config object would rewrite settings nobody touched — and with `undefined` collapsed to `null` by `JSON.stringify`, it would *clear* them. "Remove override" is offered only where there is one, and the `revertsTo` line above it names the real fallback, which is the kitchen's value rather than the platform default whenever the kitchen also overrides. Settings that are overridable in the schema but not from here say so out loud — `revenue_share_bps` is `M4`, and changing what a school is paid from the same form as its cutoff is the adjacency that produces an accident
- [x] `E10-20` **Dish and menu management screens.** `/admin/menus` edits **one** thing: a dish's food type, allergens and whether it is on the catalogue, or one dish's price and available days on one menu. Creating dishes, menus and assignments stays with `tools/bulk-import` — a file can be prepared, dry-run and reviewed, and this screen has no dry run. Writes go through `admin-dish`, which needs **`dish.edit`** for what a dish *is* and **`menu.edit`** for what it *costs* — separate in `permission` and separate here, because the person who corrects an allergen is not necessarily the person who sets prices (`D3`). A `menu_item` update is qualified by **both** ids: `menu_item` is unique on the pair, and qualifying by dish alone would reprice that dish on every menu it appears on. An unknown allergen code is a **422 naming the valid codes**, never a silent skip — `dish_allergen` and `recipient_allergen` share one vocabulary, and an unmatched code means the warning silently never fires. The screen labels the three states that look identical in a list of names: retired, not on this menu, and no food type
